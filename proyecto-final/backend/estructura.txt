🔹 Tecnologías usadas

Node.js → entorno de ejecución del servidor.
Express → framework para crear rutas y manejar peticiones HTTP.
Sequelize → ORM para conectarte a MySQL, gestionar modelos (User) y sincronizar la base de datos.
MySQL → base de datos (react_dom_orm), conectada a través de Sequelize.
dotenv → para cargar variables de entorno (.env) como puerto, JWT, credenciales DB.
Joi → para validar la información que envían los usuarios (nombre, email, password).
bcryptjs → para encriptar y comparar contraseñas.
jsonwebtoken (JWT) → para generar tokens en el login.
cors → para permitir que el frontend haga peticiones desde otro origen.



backend/
  ├─ config/db.js      ← configuración Sequelize / MySQL
  ├─ models/User.js    ← modelo de usuario
  ├─ routes/users.js   ← rutas de registro y login
  └─ index.js          ← arranque del servidor
